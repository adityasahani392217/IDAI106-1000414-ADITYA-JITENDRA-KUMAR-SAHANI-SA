# Empathy Maps — CareEase Hospital Queue App
## Design Thinking | Empathize Stage

Empathy maps capture the inner world of our users — what they Think, Feel, See, Hear, Say, and Do while in the hospital waiting experience. Each map is constructed from interview observations and survey responses.

---

## Empathy Map 1 — The Anxious Patient (Jitendra Sahani / Ramesh Gupta type)
*Representative of: Middle-aged patients visiting for chronic or serious conditions*

```
┌─────────────────────────────────────────────────────────────────┐
│                         THINK                                   │
│  "How much longer? Did they forget me? Will the results be bad?  │
│   I'm missing work. My family is waiting. What if it's serious?" │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          FEEL                                   │
│  Anxious, frustrated, ignored, disrespected, helpless.           │
│  Slight hope every time someone exits the doctor's room.         │
│  Dread when they think about the potential diagnosis.            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          SEE                                    │
│  Crowded, noisy waiting hall. Hard plastic chairs in rows.       │
│  Other patients looking just as confused and tired.              │
│  Staff busy behind a counter, rarely making eye contact.         │
│  Token numbers on a small screen that seems to never change.     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          HEAR                                   │
│  Occasional PA announcements (often inaudible).                  │
│  Crying children. Conversations between strangers.               │
│  Staff calling names loudly across the room.                     │
│  Phone notifications from WhatsApp and news apps.                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           SAY                                   │
│  "Excuse me, how long will it be?" (to staff)                    │
│  "We've been waiting almost 2 hours" (to companion)              │
│  "I need to get back to work" (under breath)                     │
│  Nothing — sits quietly and internalises the stress              │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           DO                                    │
│  Scrolls phone. Walks to the counter and back.                   │
│  Checks the token display repeatedly.                            │
│  Shifts in seat due to discomfort.                               │
│  Tries to read something but cannot concentrate.                 │
└─────────────────────────────────────────────────────────────────┘
```

**Key Insight:** This user needs transparent, real-time queue information more than anything else. Uncertainty is the root cause of almost all their stress.

## Empathy Map 2 — The Caregiver Companion (Ishant Vishwakarma / Gudiya Sahani type)
*Representative of: Young adults or family members accompanying an elderly or unwell relative*

```
┌─────────────────────────────────────────────────────────────────┐
│                         THINK                                   │
│  "Is Nani okay? What if they call her name and she doesn't hear? │
│   I am responsible for her. I need to stay alert at all times.   │
│   Nobody here cares about us or is helping us."                  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          FEEL                                   │
│  Hyper-vigilant, stressed, worried, overwhelmed.                 │
│  Guilt when they want to rest or look at their phone.            │
│  Invisible — like the system was not designed for them.          │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          SEE                                    │
│  Their relative: uncomfortable, confused, possibly in pain.       │
│  A counter where names are called without any visual support.     │
│  Other caregivers in the same helpless situation.                │
│  No signage that acknowledges companions or accessibility needs. │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          HEAR                                   │
│  PA system calls — names they might miss.                        │
│  Their relative asking "Has my name come?" repeatedly.           │
│  Announcements in English when they speak Hindi or Marathi.      │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           SAY                                   │
│  "Don't worry, I'm here" (to their relative)                     │
│  "Excuse me, can you please tell me when her number comes?"      │
│  "This system is broken" (to themselves)                         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           DO                                    │
│  Stands near counter to listen for name calls.                   │
│  Fetches water for relative. Fans them in heat.                  │
│  Checks phone while feeling guilty about it.                     │
│  Frequently looks back and forth between the door and relative.  │
└─────────────────────────────────────────────────────────────────┘
```

**Key Insight:** Caregivers need a reliable, silent alert system tied to their own phone so they can relax slightly without fear of missing a call. They also need to feel that the hospital recognises their role.

## Empathy Map 3 — The Young Tech-Savvy Patient (Aaron / Arhaan / Karan type)
*Representative of: Young adults who expect digital experiences everywhere*

```
┌─────────────────────────────────────────────────────────────────┐
│                         THINK                                   │
│  "This feels so outdated. Why is there no app for this?          │
│   I could track a pizza delivery in real time but not my turn    │
│   at a hospital. I don't even know if I'm in the right queue."   │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          FEEL                                   │
│  Frustrated, mildly impatient, slightly anxious about procedure. │
│  Surprised by how behind the hospital's systems are.             │
│  Powerless — used to controlling situations via apps.            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          SEE                                    │
│  Paper token slips. Small displays with token numbers.           │
│  Staff who do not engage with patients proactively.              │
│  People on phones, scrolling or listening to music.              │
│  A waiting room designed for 1990, not 2025.                     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          HEAR                                   │
│  Phone notifications. Ambient noise. Air conditioning hum.       │
│  Occasional names shouted from behind the counter.               │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           SAY                                   │
│  "This should be so much easier."                                │
│  "Can I at least get a notification when my turn is close?"      │
│  "There should be an app for this."                              │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           DO                                    │
│  Reads articles, watches videos, listens to music on phone.      │
│  Checks email. Talks to friends on WhatsApp.                     │
│  Paces around when sitting feels too passive.                    │
└─────────────────────────────────────────────────────────────────┘
```

**Key Insight:** This user group has the highest expectations for digital experience. They will engage most with an app that feels modern, clean, and genuinely functional — not a gimmick.

## Empathy Map 4 — The Elderly Vulnerable Patient (Priya Mehta / Lalita Devi type)
*Representative of: Senior citizens, especially those with health anxiety or accessibility needs*

```
┌─────────────────────────────────────────────────────────────────┐
│                         THINK                                   │
│  "Have they forgotten me? Should I go and ask? What if they      │
│   are angry? What if something is wrong with my results?         │
│   I cannot read that board. I cannot hear the announcements."    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          FEEL                                   │
│  Terrified, overwhelmed, invisible, ashamed to ask for help.     │
│  Deeply anxious about medical outcome.                           │
│  Physically exhausted and in pain from long wait.                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          SEE                                    │
│  Small text on digital screens she cannot read.                  │
│  English signage she cannot understand.                          │
│  Young people on phones around her.                              │
│  Staff who speak quickly and do not slow down for elderly.       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          HEAR                                   │
│  Muffled PA system — hard to decipher.                           │
│  Background noise that makes hearing even harder.                │
│  Medical jargon that she does not understand.                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           SAY                                   │
│  "I am fine" (when she is clearly not)                           │
│  "Did they call my name? I could not hear."                      │
│  Very little — tries not to draw attention to her confusion.     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           DO                                    │
│  Sits very still. Prays quietly. Clutches belongings.            │
│  Occasionally approaches counter hesitantly.                     │
│  Tries to lip-read or follow visual cues.                        │
│  Falls asleep briefly from exhaustion.                           │
└─────────────────────────────────────────────────────────────────┘
```

**Key Insight:** This user needs accessibility features as a baseline, not an afterthought. Large text, vibration alerts, Hindi language support, and visual displays are not optional — they are essential for dignified, equal care.

## Empathy Map 5 — The Parent with a Young Child (Sneha Patil type)
*Representative of: Parents managing a sick or fussy child while waiting*

```
┌─────────────────────────────────────────────────────────────────┐
│                         THINK                                   │
│  "I have a deadline at 2pm. My son is crying. The app said       │
│   30 minutes but it has been 70. I feel like a failure as both   │
│   a mother and an employee right now."                           │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          FEEL                                   │
│  Overwhelmed, guilty, stressed, embarrassed when child cries.    │
│  Frustrated by inaccurate wait time estimates.                   │
│  Desperately needs someone or something to help.                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          SEE                                    │
│  A bored, sick, fussy child with no stimulation.                 │
│  Other patients looking over at her crying child.                │
│  No children's corner, no toys, no screens for kids.             │
│  Her laptop bag, her crying son, and nowhere adequate to sit.    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                          HEAR                                   │
│  Her child crying. Other patients' sighs.                        │
│  Work notifications on her laptop.                               │
│  A PA system that could call her name at any moment.             │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           SAY                                   │
│  "Arjun, please, just for a few minutes."                        │
│  "I'm so sorry" (to other waiting patients)                      │
│  "Why does the app say 30 minutes when it's clearly not?"        │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                           DO                                    │
│  Alternates between soothing child and trying to work.           │
│  Uses phone as entertainment device for child.                   │
│  Feeds snacks to child as a distraction.                         │
│  Tries and fails to concentrate on laptop.                       │
└─────────────────────────────────────────────────────────────────┘
```

**Key Insight:** This user needs the app to also be a tool for her child — a dedicated kids' zone with interactive age-appropriate content. She also needs push notifications so she can briefly step away.

## Summary of Empathy Themes

| Theme | Affected Personas |
|-------|-------------------|
| No real-time queue information | ALL |
| Physical discomfort while waiting | Jitendra, Ramesh, Priya, Lalita |
| Accessibility barriers | Priya, Lalita, Ishant (caregiver) |
| Nothing to do / boredom | Madhuri, Arhaan, Sneha, Aaron |
| Child-related stress | Sneha |
| Language barriers | Jitendra, Gudiya, Priya, Lalita |
| Medical anxiety (unaddressed) | Jitendra, Priya, Ramesh, Arhaan |
| Missing turn due to auditory announcements | Lalita, Priya |
| Caregiver fatigue | Ishant, Gudiya |
